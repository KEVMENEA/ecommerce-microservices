# ecommerce-microservices
# E-Commerce Microservices Platform

A production-oriented e-commerce backend built with Java 21 and Spring Boot,
demonstrating microservice architecture, event-driven communication,
distributed transactions, security, observability, CI/CD, and Kubernetes.

## Tech Stack

**Backend**
- Java 21
- Spring Boot
- Spring Cloud
- Spring Cloud Gateway
- Spring Data JPA / Hibernate

**Data**
- PostgreSQL
- Redis
- Flyway

**Messaging & Distributed Transactions**
- Apache Kafka
- Transactional Outbox Pattern
- Saga Pattern
- Idempotent Consumers
- Retry / Dead Letter Topics

**Security**
- Spring Security
- Keycloak
- OAuth 2.0 / OpenID Connect
- JWT

**Infrastructure**
- Docker / Docker Compose
- Kubernetes / GKE
- Jenkins
- GHCR
- Google Cloud

**Observability**
- OpenTelemetry
- Micrometer
- Prometheus
- Grafana
- Jaeger
